Правило вывода результатов PowerShell команды/блока команд составленных тобой: 
  1. Записываем весь результат. 
  2. Вывод на экран (ошибки красным цветом) 
  3. Копирование в буфер.

Правило формирование валидных контейнеров AGX1:C по следующей формуле:
  AGX1:C:<B>:<H>
  где:
  B = Base64URL(UTF8(J))
  H = SHA256("AGX1:C:" + B)
  J — канонический JSON:
  {"action":"команда/блок команд","args":{}}
  Каноникализация JSON: UTF-8, ключи отсортированы, без пробелов между элементами.
